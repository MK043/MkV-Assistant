# MkV Sales Manager CRM — Lab 4 & Lab 5 Specification

## Project Overview
High-performance React single-page application (SPA) reproducing the full UI/UX design and business workflows from Labs 1-3.

## Requirements
### Lab 4
- Minimal pages implemented: 5 pages (Master Hub, Analytics Dashboard, AI Creative Studio, Campaigns & Rules, Ad Fatigue Detector) + Auth Modal.
- 100% Modular CSS (`*.module.css`) without ANY CSS frameworks (no Tailwind, Bootstrap, etc.).
- Custom CSS design system matching the Figma Dark Slate mockups (`#070B14`, `#131D31`, `#6366F1`, `#10B981`, `#F43F5E`).
- Branch `feature/lab4-modular-css-components`, PR to `main`, and report docx.

### Lab 5
- Full client-side routing via `react-router-dom` v6.
- Active route state indicators on sidebar and master hub.
- Branch `feature/lab5-routing-navigation`, PR to `main`, and report docx.
