# Векторні макети інтерфейсу (SVG Mockups)

У цій папці розміщено векторні дизайн-макети інтерфейсу платформи **MkV Sales Manager & Assistant CRM**:

1. **`01_master_hub_overview.svg`** — Головний робочий простір платформи (Master Hub).
2. **`02_analytics_dashboard.svg`** — Панель крос-платформної аналітики (Analytics Dashboard).
3. **`03_ai_creative_studio.svg`** — Креативна ШІ-студія та відео-розкадрування (AI Creative Studio).
4. **`04_campaigns_management.svg`** — Центр управління кампаніями та медіабаїнгом (Campaigns & Media Buying).
5. **`05_ad_fatigue_detector.svg`** — Детектор вигорання аудиторії та ротація хуків (Ad Fatigue Detector & Hooks).
6. **`06_auth_modal.svg`** — Модуль безпечної авторизації таргетолога (OAuth 2.0 SSO + API Token).

### Як відкрити та редагувати макети:
* **Figma**: Створіть новий файл у Figma та перетягніть (Drag & Drop) будь-який `.svg` файл на робочу область. Усі тексти використовують шрифт **Inter** і підтримують редагування.
* **Браузер**: Відкрийте відповідні HTML-файли в корені репозиторію (`01_analytics_dashboard.html`, `index.html` тощо).
